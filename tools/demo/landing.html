// Highlights

What this fork adds

The features that stand out most against stock ESPuino. The full, commit-by-commit list lives in the repository README.

01

Cyberpunk web interface

Management and access-point pages rebuilt in neon, with six switchable looks — from Cyberpunk to kid-friendly Waldhaus, Wölkchen, Pixelheld, Robo and Kreidetafel.

02

Fully offline & installable

Every library and font is vendored and served gzipped straight off the ESP32. No CDN, no internet — and it installs as a PWA.

03

RFID that keeps up

Presence detection, SLIX2 support, learn-mode straight from the browser and resume positions that survive a reboot.

04

Apple HomeKit

The player shows up as a native HomeKit accessory — pair it with a QR code and control it from the Home app or Siri.

05

Backup & sync

Export and restore the whole configuration, sync RFID assignments between devices, and keep listening statistics per tag.

06

Equalizer & per-path rules

A real EQ with rules that stick to a folder, so the loud audiobook and the quiet radio play stay at the same level.

// Themes

Six looks, one interface

The theme is remembered per browser — neon for the workshop, something softer for the kids' tablet.

// Hardware

The box it lives in

The enclosure was drawn by hand in CAD — no AI involved — and prints on any FDM machine. RFID cartridges snap onto the top plate and start a playlist the moment they touch down.

  • ESP32 with PN5180 RFID reader and an SH1106 OLED
  • Rotary encoder, mechanical keycaps, Neopixel ring
  • Battery powered with a real-time clock for wake-ups
  • Printable STL files for case, panels, handle and cartridges
Get the STLs

Full disclosure: the firmware and web interface in this fork are largely vibe-coded (AI-assisted). The hardware is not.

// No hardware required
